# iOS Development Environment Setup

## Required tools

1. **Mac:** A Mac is required for the standard native iOS development workflow.
2. **Xcode:** Apple's IDE for building, testing and debugging iOS applications.
3. **Xcode Command Line Tools:** Provides command-line developer utilities, including build tools.
4. **iOS Simulator:** Runs virtual iPhone and iPad devices for app testing.
5. **Swift:** The programming language used for iOS application development.

## Basic setup checklist

- [ ] Confirm access to a compatible Mac.
- [ ] Install Xcode from the Mac App Store or Apple Developer downloads.
- [ ] Open Xcode and complete its additional component installation.
- [ ] Install or verify Command Line Tools using `xcode-select --install`.
- [ ] Verify the selected developer directory using `xcode-select -p`.
- [ ] Verify Swift using `swift --version`.
- [ ] Open Xcode and download an iOS Simulator runtime if required.
- [ ] Create a test iOS project and run it in the Simulator.

## Note for Windows learners

Swift language syntax and many command-line exercises can be practised on Windows with a compatible Swift toolchain. However, Xcode and Apple's iOS Simulator are macOS tools. Do not mark the complete iOS environment setup as finished until it has been verified on a Mac.
