# Wipro iOS COE – Swift Learning Repository

This repository documents my learning and practice during the Wipro iOS Centre of Excellence (COE) drive.

## Learning topics covered

- Swift introduction, features, syntax, variables and constants
- Operators and expressions
- Collections: arrays, sets and dictionaries
- Enumerations, structures and classes
- Optionals and optional handling
- Automatic Reference Counting (ARC) and memory management
- Functions, parameters and return types
- Closures and higher-order functions
- Protocols and extensions
- Generics and error handling
- iOS development prerequisites and environment setup

Each Swift file contains small examples for understanding the corresponding concept. These are practice examples, not production applications.

## Running the examples

On macOS with Xcode or Swift Command Line Tools installed:

```bash
swift path/to/Example.swift
```

You can also create a Swift Playground in Xcode and paste the examples into it. The iOS Simulator and full iOS app development workflow require macOS and Xcode. Swift language practice can be done separately using a compatible Swift toolchain.
