### Key takeaways

- Swift is a strongly typed language with type inference, optionals and modern language features.
- Collections provide ways to store and organize multiple values.
- Structures and classes model data, while enums represent a fixed set of related cases.
- Optionals make the possibility of missing values explicit.
- ARC manages the lifetime of class instances through reference counting.
- Functions, closures, protocols, extensions and generics support reusable and flexible code.
- Error handling makes failures explicit and manageable.
